# MeowDoku Android v2.0.0

發布日期：2026-09-29

## 2.0 全新尋貓旅程

- 全面更新主選單、大地圖、節點與專屬場景，從家園街區一路探索至宇宙空間站。
- 重新生成 1,400 關內建關卡，提供 6×6～12×12 的一般與高難度挑戰。
- 普通主線共 70 關，各節點第一關通過後逐步開放支線、下一節點及對應高難度；全主線通過後解鎖蟲洞與自由選曲。
- 新增關卡手冊，每頁 50 關，可切換難度與章節，統一顯示通過、完成、完成率及中途紀錄。
- 支援 2.0 隔離的線上追加關卡；目前提供 2,800 關追加，合併納入進度與遊戲歷史，對應大關／難度解鎖後可遊玩，新增關卡不必重裝 App。
- 新增偵測器、小魚乾、麵包屑，每次全新挑戰固定提供 1／1／3 次；中途載入不重置數量，加入道具圖示、數量及完整效果／故事說明。
- 保留隨機關卡、完整盤面分享碼、已保存關卡管理、中途紀錄與盤面上傳。
- 過關選項調整為選關、繼續深入及條件式下個地點，高難度同步節點路線。
- 統一肉球顯示、淺色立體按鈕及深色棋盤；保留原始、像素、磁磚、紙張四種風格，改善大盤面繪製負擔。
- 新增關卡專屬 BGM，主線完成後開放自由選曲、試聽、音量及單曲／全曲循環。

## 安裝與紀錄

- 最低支援 Android 6.0。
- 2.0 採全新關卡與獨立進度，不混用 1.x 關卡紀錄。
- 套件名稱維持 `com.nanbu.meowdoku`，安裝 2.0 會更新原有 App，不可與 1.x 並列安裝。
- 請勿先解除安裝 App；解除安裝會清除本機資料。
